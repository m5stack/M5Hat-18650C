# **HAT 18650C V1.1**

## Overview

### SKU:U080-V11

M5Hat-18650C is a stackable 18650 Li‑ion battery power module in the M5Stack HAT series. It provides a single 18650 cell slot and an integrated USB‑C charging port, delivering regulated system power to the host device. The onboard INA226 high‑precision I²C voltage / current monitor (16‑bit ADC, 10 mΩ shunt) enables real‑time measurement of bus voltage, charge / discharge current, and power consumption, while the AW32257 switch‑mode Li‑ion charger supports programmable charge current, regulation voltage, and Boost (OTG) output with comprehensive charge‑status and fault reporting. An I²C interface allows the host MCU to read all parameters and configure charging behavior at runtime. It is suitable for portable instruments, field data loggers, handheld controllers, and any battery‑powered M5Stack application requiring accurate power monitoring and intelligent charge management.
